# math‑practice‑demo
> Student portfolio demo｜Adaptive math practice web app

A lightweight frontend‑only web application for calculus basic drill practice, inspired by spaced‑repetition vocabulary‑learning apps.

### Concept
Transfer spaced‑repetition review logic to math fundamental training (limit, derivative, integral).
Generate variant exercises for wrong‑answered questions instead of repeating original problems.
All user data stored inside browser LocalStorage, no backend database required.

### Features
‑ Initial ability diagnosis
‑ Daily practice session
‑ Spaced repetition review for wrong points
‑打卡 streak & simple data dashboard

### Tech stack
HTML + Tailwind CSS + Vanilla JS
API: DeepSeek‑v4‑flash for exercise generation
Deployed on Vercel

### Limitations
‑ Only for basic calculus calculation drills
‑ AI judge & answers may contain errors, not substitute for real textbooks
‑ All data saved locally in browser; clearing browser cache will lose progress

### Statement
Product idea & review logic are self‑designed. AI assists code implementation only.
See `plan.md` for full project design document.
